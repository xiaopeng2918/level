# Goods Sort Challenge

网页版限时货架三消，支持粘贴原版风格关卡数据。

## 关卡数据格式

```js
[
  [[0,18,18],[38,33,0]], // 三格货架：每层 3 个
  [[9],[18],[56]],       // 单格货架：每层 1 个，只出不进
]
```

- `0` = 空位
- 非 0 = 物品类型 ID
- 每层长度只能是 **1 或 3**
- `999` = 特殊物，**单击即消除**（不用凑 3）

## 胜负

- **胜利**：清完所有物品
- **失败**：
  1. 时间耗尽
  2. **死局**：已翻开的首层无法再消除（没有 999，且任何颜色都凑不满 3 个），并且无法再把任何货架最外层整层搬空以翻出新层
     - 不一定要「所有三格都塞满」才算死局
     - 「翻新层」= 把某架当前层物品全部挪到其他空位，使该层清空（下层可以没有物品）

## 模拟规则详解

白话版流程、选步分值与难度分公式见：[模拟规则说明.md](./模拟规则说明.md)

## 难度分析（仅移动，不看时间）

页面底部点「分析难度」（可改「模拟局数」，范围 10–50000，默认 120），或命令行：

```bash
node --input-type=module -e "
import { analyzeLevel } from './analyze.js';
const level = JSON.parse(process.argv[1]);
console.log(JSON.stringify(analyzeLevel(level, { trials: 120, strategy: 'greedy' }).summary, null, 2));
" '你的关卡JSON'
```

输出含：通关率、卡死率、卡死时进度、半程前卡死率、通关步数分位、难度分 0–100 与档位。

## 批量关卡模拟

页面下方「批量关卡模拟」：

1. 拖入含 `物品数据` / `itemData` 列的 `.xlsx`（表头可含中英两行）
2. 设定每关局数（默认 20）
3. 点「开始批量模拟」，指标写回对应行
4. 「下载结果表」导出带结果列的 Excel

结果列包括：模拟难度分/档、通关率、卡死率、步数上限耗尽、卡死进度、半程前卡死、通关中位/P90/平均步数、进度桶、结构统计等。
